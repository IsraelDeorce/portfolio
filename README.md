# Portfolio

Personal portfolio app built with React, TypeScript, Vite, and Express.

## Requirements

- Node.js `24.x`
- npm

## Development

Install dependencies:

```bash
npm install
cd server && npm install
```

Start the frontend dev server:

```bash
npm run dev
```

## Scripts

```bash
npm run dev
npm run lint
npm test
npm run build
npm start
```

## Notes

- `npm run build` creates the frontend bundle in `dist/`
- `npm start` serves the built app through the Express server
